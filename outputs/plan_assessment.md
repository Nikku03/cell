## Rating: A-minus (strong)
- Methodology / rigor: 9/10 (leak control, self-refutation on honest metrics,
  risk-coverage reframe)

## Why not higher — the measured ceiling
Variance decomposition of essentiality FLIPS (50,574 genes in flippable
families, essential in some orgs / not others — the conditional zone):

| signal | variance explained |
|---|---|
| organism identity (lifestyle/env proxy) | 7.5% |
| gene/OG identity (already used by family_frac) | 13.6% |
| residual = organism × gene interaction | ~79% |

The 79% residual IS the environment-dependence. It is provably not
reconstructable from genome + organism identity. Every model plateaus
because ~79% of the conditional signal is absent from the data in hand.
This is a property of the DATASET, not the model — no architecture recovers it.

## The only two moves that change the rating
1. Fitness Browser condition matrix = literally the 79% residual
   (gene × condition fitness). The only data that contains the prize.
2. One wet-validatable surprise from the confident 39% subset — orthogonal
   path to "groundbreaking" that needs no new data.

Until one is in motion, further model changes only rearrange the solved 21%.
