# PREDECLARE — written before Phase 1 and Phase 2 were executed

Committed before any fit, any correlation, and any `tau` estimate was computed. Phase 0
(inventory) had been completed at the time of writing; nothing downstream had been run.

## What Phase 0 established (facts, not gates)

Three routes to `tau` exist, and only three. Phase 0 answers whether each is present:

- **(a) lineage / mother-daughter identifiers** — needed for Route A
- **(b) pre-treatment time series** — needed for Route B
- **(c) same cell measured at two separated times (of the STATE variable)** — needed for Route C

## Decision rule, fixed in advance

**If (a), (b) and (c) are all absent, `tau` is declared NOT RECOVERABLE and Phase 2 is not run.**
No substitute quantity is promoted into its place. In particular the following are explicitly
ruled out in advance as substitutes, because each is a different quantity that could be mistaken
for `tau`:

1. `K_deg`, `alpha_0`, `alpha_1` — per-cell fitted kinetic parameters of caspase-8 activation.
   These are rates *within* the death cascade after the drug arrives. They are not the relaxation
   of cell state toward the population distribution.
2. The spread of `pC8(0)`/`FLIP(0)` across cells. A distribution width is not a timescale.
3. Any timescale read off the FRET trace. FRET is the death reporter, not the state variable.
4. Any number digitised from a figure.

## Phase 1 gate

- **R0** — reproduce a published quantity from the raw files to within 5% relative.
  Quantity chosen in advance: **the per-cell simulated FRET trajectories of Figure 2**,
  regenerated by integrating the paper's own ODE with the paper's own deposited per-cell
  parameters, compared against the paper's own deposited experimental FRET traces.
  Statistic: Pearson r and normalised RMSE between my simulation and their deposited simulation
  target, per cell, across all 6 condition groups (R/S x 25/50/100 ng), 24 cells total.
  Bar: median Pearson r >= 0.95 between simulated and experimental traces, AND my re-integration
  must agree with their model structure well enough that no cell has r < 0.5.
  **Secondary R0b**: tolerant fraction per dose, computed by counting deposited per-cell fitted
  values (R vs S), reported against the paper's stated values if those can be retrieved.

  R0 is a real test: if I mis-order the parameter vector, mis-scale time by K1, use the wrong
  TRAIL0, or transpose a matrix, r collapses. It could fail.

## Phase 2 gates (run only if a route exists)

- **T1** `tau` > 0 and its 95% CI excludes zero.
- **T2** CI spans < a factor of 5; otherwise report as a bound, not a measurement.
- **T3** exponential fits: report R^2 and residuals vs lag; do not force it if residuals are structured.
- **T4** split-half stability: two random halves agree within CIs.
- **T5** if two routes available, they agree within CIs.
- **T6** negative control: shuffle cell identity; estimator must return no significant decay.

Expected direction, stated in advance: if `tau` were measurable I expect it of order the cell
doubling time (state inherited at division then diverging), i.e. hours, not minutes and not days.
This expectation is recorded so that a wildly different answer is treated as a suspected bug first.

## Phase 3 gates

Fit `s(x)` as hard threshold, logistic, and Gompertz/exponential. Report all three by AIC and
carry all three forward. Record explicitly how `x` is defined.

## Phase 4 gates

- **S1** floor: bursty birth-death Fano factor matches its exact analytic value to < 1e-6 relative.
- **S2** truncation: `ratio` stable to < 1e-4 across three state caps.
- **S3** zero-heterogeneity control: `ratio` == 1 at every gap to >= 1e-9.
- **S4** shuffle control: `ratio` collapses to ~1.
- **S5** direction: print the sorted array, do not assert monotonicity.
- **S6** spread: report the full range across all three kill functions.

## Gate honesty check, applied in advance

For each gate: could it fail if the code were wrong?
- R0 — yes (see above).
- T6, S3, S4 — yes; these are the controls that catch a broken estimator.
- S1, S2 — yes; they compare against an exact analytic value and against each other.
- T1, T2 — yes.
- **S5 is not a gate**, it is a print. Recorded as such rather than dressed up as a test.
