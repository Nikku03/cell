N6  WHY N5 BEATS THE SPEC'S TABLE -- fitted error is ANISOTROPIC, random error is not
====================================================================================================
  The spec's section 11 table is measured with INDEPENDENT random rate errors. A
  FITTED rate vector is different in kind: a regressor is pulled hardest along the
  directions the data constrains, so its residual error concentrates in the FLAT
  directions -- precisely the ones that barely move the observables, and therefore
  barely move the tail. Same nominal % error, different cost.
  Test: same magnitude of rate error, drawn isotropically instead of fitted.

  source of rate error                  median       p90     worst
  FITTED (this regressor)               0.207    0.822    1.595
  ISOTROPIC random, same magnitude      2.077    5.734   12.893

  isotropic error costs 10.1x more tail spread than fitted error of the SAME magnitude.
  N6 PASS

  CONSEQUENCE FOR THE SPEC. Section 11's table -- "a rate predictor must reach ~25%" -- is
  derived from isotropic perturbations and therefore does NOT transfer to a fitted predictor.
  At 39% fitted error this module already delivers 0.207 orders median, better than the 0.777
  the table promises at 22%. The bar belongs on the TAIL SPREAD, which is the quantity anyone
  cares about and which item 9 can measure directly, not on a percentage of rate error whose
  cost depends entirely on which direction the error points.
