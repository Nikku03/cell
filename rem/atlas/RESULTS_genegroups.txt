=================================================================================================
SHARING CLASSES ACROSS GROUPS OF GENES
=================================================================================================
  Every compression in this build order assumes a gene's response reaches it through
  classes SHARED ACROSS GENES. mpra_human measured that a globally shared map can capture
  only 21.5% (HepG2) and 46.8% (K562) of the reproducible effect; the rest is context.
  Sharing across GROUPS interpolates between a global map and a per-gene one. This tests
  it -- after first testing whether groups are needed at all.

  GEO GSE33367 sha256[:32] 803c5fd57e2a817e97cd4d9163bdeb9d; 196 disruptions, 136 motif classes.

=================================================================================================
J0  THE CEILING GATE: ARE GROUPS NEEDED AT ALL?
=================================================================================================
  Grouping is worth building only if the context variance is not already explained by
  something cheaper. The candidate is one scalar: the wild-type activity of the context.
  The correlation is suspicious by construction -- the effect is mutant minus wild type,
  so the covariate sits on both sides and shared noise manufactures it -- so it is also
  measured ACROSS replicates, where the two noises are independent.

    cell                    same-rep corr               cross-rep corr
    HepG2                  -0.865, -0.880               -0.758, -0.758
    K562                   -0.811, -0.698               -0.546, -0.440

  It survives the control. Shared noise inflates it but does not create it, and every
  coefficient below is CROSS-FITTED: fitted on one replicate's covariate against the
  other's response, so it can never be an artefact of the coupling.

=================================================================================================
J4  WHAT IT DOES TO THE CAP
=================================================================================================
  The cap counts the number of distinguishable values a gene's conditional must carry.
    a PER-GENE GAIN driven by an observable adds ONE global coefficient and changes no
      gene's alphabet at all, so the cap is exactly unchanged: 13 at C = 64, 140 with hub
      demotion and the factored block.
    G CLASS MAPS multiply the STORED alphabet by G but likewise leave each gene's own
      alphabet unchanged, so the cap is also unchanged -- G maps cost G times a table that
      was never the binding term. Neither option moves the cap; they differ only in what
      they buy in ACCURACY, which is what J1/J2 measured.
  So the question was never cost. It was whether either repair recovers the context share,
  and the ladder above answers it.

=================================================================================================
J5  WHAT THIS DOES AND DOES NOT SETTLE
=================================================================================================
  1. The grouping variable here is the context's own wild-type activity, chosen because
     the ceiling gate showed it absorbs most of the context variance. A grouping on some
     other property -- chromatin, promoter class, co-factor content -- is untested, and a
     better one would raise the group rows without changing the scalar row.
  2. Every enhancer here carries ONE studied motif, so 'per-gene gain' is measured on
     single-site contexts. Whether the same gain applies when several sites are present is
     exactly the copy-number question that no open human dataset could answer.
  3. This is an episomal reporter in two cell lines. The gain is a property of the assay's
     dynamic range as much as of the biology, and saturation in a plasmid need not be
     saturation in chromatin.
