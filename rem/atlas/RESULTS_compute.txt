=================================================================================================
WHAT DOES A WHOLE CELL COST, UNCOMPRESSED?
=================================================================================================
  Every line is labelled MEASURED (timed here), ANCHORED (validated against an exact
  answer), or ASSUMED (literature count, given as a range). A costing whose provenance
  has been lost is the failure mode this is guarding against.

=================================================================================================
W1  PRIMITIVES, MEASURED ON THIS MACHINE
=================================================================================================
  MEASURED  Recon3D FBA LP, 5835x10600, 40425 nonzeros : 0.785 s
  MEASURED  exact CME, 5184 states, 50220 nonzeros : 0.28 s (residual 9e-15)
  MEASURED  exact SSA, 2000 species / 4000 reactions, pure Python : 29,929 events/s
  ASSUMED   a compiled SSA reaches 1e+07 events/s. Pure Python here is
            334x slower; the gap is stated, not folded in silently.

=================================================================================================
W2  THE COST MODEL, ANCHORED AGAINST AN EXACT ANSWER
=================================================================================================
  A rate is only usable if the sampler it describes is correct. Two-state switch, whose
  stationary law is known in closed form:
    k_on=1.3 k_off=0.7   20000 events: P(on) 0.64991 vs exact 0.65000  rel err 1.36e-04  ok  (1,805,827 ev/s)
    k_on=1.3 k_off=0.7  200000 events: P(on) 0.65160 vs exact 0.65000  rel err 2.46e-03  ok  (1,764,667 ev/s)
    k_on=0.4 k_off=2.1   20000 events: P(on) 0.15995 vs exact 0.16000  rel err 3.26e-04  ok  (1,792,629 ev/s)
    k_on=0.4 k_off=2.1  200000 events: P(on) 0.16095 vs exact 0.16000  rel err 5.91e-03  ok  (1,802,443 ev/s)
  W2: PASS -- the sampler converges to the exact answer, so its event rate is usable

=================================================================================================
W3  THE TIERS, WITH THE ARITHMETIC WRITTEN OUT
=================================================================================================
  ASSUMED   expressed species per mammalian cell : 1e+04 to 2e+04
  ASSUMED   reaction events per cell cycle       : 1e+12 to 1e+14
            (metabolic turnover dominates; protein synthesis is 1e9-1e10 events, peptide
             bonds 1e12-1e13, so the range spans reaction-level and elementary-step)

  T1  DETERMINISTIC ODE / FLUX, one cell cycle
      ASSUMED 1e5 stiff steps x 1e7 flops/step (sparse Jacobian with fill-in)
      = 1e+12 flops -> 16.7 min at 1 GFLOP/s effective
      MEASURED cross-check: one Recon3D LP is 0.78 s; a flux-balance cell cycle is
      a few thousand such solves, 39.2 min.
      VERDICT: feasible on a laptop. This is roughly what published whole-cell models do.

  T2  ONE STOCHASTIC TRAJECTORY, exact SSA, one cell cycle
      1e+12 events / 1e+07 events per s = 1.16 d
      1e+14 events / 1e+07 events per s = 116 d
      VERDICT: hours to weeks per trajectory. Feasible, and the low end is routine.

  T3  ENSEMBLE FOR MEANS (1e3 trajectories, embarrassingly parallel)
      3.17 yr of CPU time -> 2.78 h on 10,000 cores
      317 yr of CPU time -> 11.6 d on 10,000 cores
      VERDICT: feasible on a cluster. Means and variances are not the obstruction.

  T4  ENSEMBLE FOR A RARE EVENT, no rare-event method
      To resolve a probability p to 10% you need about 100/p trajectories.
               p   trajectories       CPU time   on 1e4 cores  vs exaflop-yr
           1e-03          1e+05         317 yr         11.6 d       3.17e-07
           1e-06          1e+08    3.17e+05 yr        31.7 yr       3.17e-04
           1e-09          1e+11        317 Myr    3.17e+04 yr       3.17e-01
           1e-13          1e+15   3.17e+03 Gyr        317 Myr       3.17e+03
      VERDICT: this is where it breaks. A 1e-13 conjunctive event -- the class this build
      order has been measuring all along -- is not reachable by direct sampling at any
      scale. Rare-event methods exist and are the reason REM has a tail machinery at all.

  T5  THE EXACT JOINT DISTRIBUTION
      MEASURED here: 5184 states = 0.28 s. Cost scales with the state count.
          20 binary species: 2^20 = 1e6 states -> 56.4 s
          40 binary species: 2^40 = 1e12 states -> 1.87 yr
         100 binary species: 2^100 = 1e30 states -> 2.16e+09 Gyr
        1000 binary species: 2^1000 = 1e301 states -> 1.83e+280 Gyr
       12000 binary species: 2^12000 = 1e3612 states -> 1e3601 years
      (reported in log space above 1e300 -- the direct arithmetic overflows a float64,
       which is itself the answer to the question)
      VERDICT: impossible by a margin that has no useful name. 100 binary species already
      exceeds the age of the universe on this machine, and a cell has 1e4.
      statedim measured the treewidth-bounded version on real topology at >40, so even
      the compressed exact answer starts at 2^40 = 1e12 entries per bag and grows.

=================================================================================================
W4  WHERE IT CROSSES, AND BY HOW MUCH
=================================================================================================
    tier                                           one cell cycle    feasible?
    T1 deterministic ODE / flux                          16.7 min          yes
    T2 one stochastic trajectory (low estimate)            1.16 d          yes
    T2 one stochastic trajectory (high estimate)            116 d          yes
    T3 1e3-trajectory ensemble, 1e4 cores                  2.78 h          yes
    T4 direct sampling of a 1e-6 event, 1e4 cores          31.7 yr           NO
    T4 direct sampling of a 1e-13 event, 1e4 cores          317 Myr           NO
    T5 exact joint, 100 binary species               2.16e+09 Gyr           NO

  The line is between T3 and T4, and it is not a gentle slope. Means and variances of a
  whole cell are a cluster job today. The conjunctive rare events that decide whether a
  lesion sterilises, whether any cell survives, whether a memory element ever flips are
  15 to 20 orders of magnitude past that, and no amount of hardware closes it -- which is
  the entire reason this build order is about representations rather than about compute.

=================================================================================================
W5  WHAT IS ASSUMED, AND WHAT MOVES IF IT IS WRONG
=================================================================================================
    ASSUMED  mammalian protein molecules                          1.00e+09 to 1.00e+10
    ASSUMED  mammalian mRNA molecules                             1.00e+05 to 1.00e+06
    ASSUMED  mammalian metabolic reaction events per cell cycle   1.00e+12 to 1.00e+14
    ASSUMED  mammalian protein synthesis events per cell cycle    1.00e+09 to 1.00e+10
    ASSUMED  peptide-bond events per cell cycle                   1.00e+12 to 1.00e+13
    ASSUMED  cell cycle length (s)                                7.20e+04 to 1.70e+05
    ASSUMED  genes / expressed species                            1.20e+04 to 2.00e+04
    ASSUMED  TRRUST measured genes                                2.86e+03 to 2.86e+03
    ASSUMED  compiled SSA event rate                          1e+07 /s
    ASSUMED  large-machine throughput                         1e+18 flops/s

  If the event count is wrong by 10x, T2 and T3 move by 10x and stay feasible; T4 moves
  by 10x and stays impossible by 14 orders instead of 15. If the compiled SSA rate is
  wrong by 100x, the same holds. NO plausible error in these inputs moves the T3/T4
  boundary, which is why the conclusion is robust even though the inputs are ranges.
  What WOULD move it is a rare-event method, which is a change of algorithm and not of
  hardware -- and this build order has spent itself finding that the obvious ones fail.
