W1  THE DEGENERATE OPTIMUM, REPORTED RATHER THAN HIDDEN
=================================================================================================
  The per-gene factor is exponential in the OCCUPIED CLASSES per gene, which is a property
  of the assignment. An unconstrained greedy optimiser on that cost was run first:
    random C = 64 assignment : cost 1.001e+10, mean occupied classes 1.84
    unconstrained optimum    : cost 2.315e+04, mean occupied classes 1.00
  It reaches the theoretical minimum by putting every controller in ONE class, which is
  the plain count -- refuted on promoter data at 6.29 noise floors. A cost optimiser with
  no accuracy constraint will always rediscover the cheapest refuted representation.
  W1: ledger U in this module's own probe. Every alignment below is CONSTRAINED to keep
  the classes balanced, and the constraint is stated before the number.

W5  THE ACCURACY SIDE, BECAUSE W4 IS ONLY A COST STATEMENT
=================================================================================================
  signed.py measured, on 5,790 real promoters, how far each class resolution sits from
  identity: C = 2 is 2.61 noise floors out, C = 8 is 1.52, C = 32 is 1.30, and C = 64 is
  0.19 -- the smallest resolution inside one floor. So a cap reachable only at C = 2 or 3
  is the plain count wearing a larger number, and does not count.

=================================================================================================
W6  WHAT BREAKS NEXT
=================================================================================================
  1. The class structure W2 found is real but partial: about half of genes still have
     mixed regulators at |C| = 122, and those genes set the worst-case per-gene factor,
     which is what the sum is dominated by.
  2. The alignment is a greedy heuristic under a balance constraint. Its numbers are upper
     bounds on the achievable cost and can only understate the prize, never overstate it.
  3. The accuracy figures are from YEAST promoters carrying designed sites, transferred to
     a HUMAN regulatory network. That transfer is the weakest link in the whole chain and
     nothing here strengthens it.
  4. The block factorisation is correct and available whenever the per-gene term stops
     binding. It is banked, not discarded.
