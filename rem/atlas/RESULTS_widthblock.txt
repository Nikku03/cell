W1  THE DEGENERATE OPTIMUM, REPORTED RATHER THAN HIDDEN
=================================================================================================
  The per-gene factor is exponential in the OCCUPIED CLASSES per gene, which is a property
  of the assignment. An unconstrained greedy optimiser on that cost was run first:
    random C = 64 assignment : cost 1.001e+10, mean occupied classes 1.84
    unconstrained optimum    : cost 2.315e+04, mean occupied classes 1.00
  It reaches the theoretical minimum by putting every controller in ONE class, which is
  the plain count -- refuted on promoter data at 6.29 noise floors. A cost optimiser with
  no accuracy constraint will always rediscover the cheapest refuted representation.
  W1: ledger U in this module's own probe. Every alignment below is CONSTRAINED to keep
  the classes balanced, and the constraint is stated before the number.

W2  DOES THE NETWORK CARRY CLASS STRUCTURE, AGAINST A MATCHED SHUFFLE?

  The one class label this network actually carries is TRRUST's own regulatory mode per
  EDGE. If a gene's regulators are all the same kind its factor is small at NO accuracy
  cost, because the classes are given by the data rather than chosen. The control shuffles
  the modes across edges keeping their counts, which is the null that matters.

  representation, the block, or the class map. It is a HUB, which is the same object that

  AND THE ALIGNMENT ATTEMPT THAT FOLLOWED FROM THE WRONG DIAGNOSIS, RECORDED. A balanced
  greedy class alignment was built before this measurement. It made things WORSE, by up to
  28x, and the reason is a specification error: with C = 64 classes and only |C| = 13
  controllers the balance cap is ceil(13/64) = 1, so every controller is FORCED into its
  own class -- the worst case, not a balanced one. A balance constraint is meaningless
  when there are fewer items than classes, and at these widths there always are.

=================================================================================================
W4  IF THE COST IS A MAX, DEMOTE THE FEW GENES THAT SET IT
=================================================================================================
  Carry the top-m most expensive genes at the PLAIN COUNT, k(L+1)+1, which is polynomial,
  and everything else at C = 64. The accuracy loss is then CONFINED to m genes instead of
  being spread over all of them, and it is measurable as a coverage figure.

     genes demoted  % of all genes   cap |C|  edge coverage
                 0           0.00%        13         26.6%
                 1           0.03%        14         27.6%
                 2           0.07%        16         29.5%
                 5           0.17%        16         29.5%
                20           0.70%        39         44.3%
               100           3.50%       140         71.7%
               500          17.48%       140         71.7%

  W4: demoting 100 of 2861 genes -- 3.5% of them -- takes the cap from 13 to 140
  controllers and edge coverage from 26.6% to 71.7%. It SATURATES at 100: demoting 500 buys
  nothing more, which means a different term has taken over as binding.

=================================================================================================
W5  AND NOW THE BLOCK BINDS, SO W0's VERDICT FLIPS
=================================================================================================
  W0 priced the block at zero and found the cap unmoved, correctly. That verdict was
  about the cap AS IT THEN WAS. Once the hubs are demoted the binding term changes, and
  the factorisation W0 called pointless becomes the thing the cap rests on.

      demoted   pattern 2^|C|   class-count   FACTORED 2^(w+1)
            0              13            13                 13
           20              36            14                 39
          100              39            14                140

  At zero demotions the block representation is worth NOTHING -- all three give the same
  cap. At 100 demotions it is worth 140 against 39, a 3.6x difference in the cap and
  71.7% against 44.3% in coverage.
  METHODOLOGICAL POINT, and it is the useful half of this module: a ceiling gate prices a
  term against the CURRENT binding constraint. Its verdict is correct at the time and is
  NOT permanent. When the constraint moves, re-run the gate rather than trusting it.
  Note also that the class-count BLOCK is worse than the plain pattern at these widths --
  with one controller per class its cost is 10 per controller against the pattern's 2 --
  which never mattered while the block was not binding and matters now.

=================================================================================================
W6  THE ACCURACY SIDE, AND WHAT BREAKS NEXT
=================================================================================================
  W4 is a COST statement. What it costs in accuracy is that 100 genes drop from C = 64,
  which signed.py measured at 0.19 noise floors from identity, to the plain count at 6.29
  floors. That is a large loss on 3.5% of genes and no loss on the other 96.5%, which is
  a different kind of trade from every earlier one in this build order -- those all
  degraded every gene at once.

       genes representation          floors from identity  share of genes
        2761 class count C = 64                      0.19           96.5%
         100 plain count                             6.29            3.5%

  Whether that trade is acceptable is not a cost question and this module cannot settle
  it. The demoted genes are the most-regulated in the network -- CDKN1A, VEGFA -- which
  are exactly the genes a whole-cell model would most want to get right. Demoting the
  hubs buys the cap by giving up on the genes the cap was wanted for, and saying so is
  the result rather than a caveat on it.

  What breaks next: at 140 controllers the block binds, and the elimination width grows
  as roughly |C|^0.78, so 2^(w+1) passes the bar around |C| = 150. Beyond that neither
  term is polynomial and there is no third term to demote.
