K3  THE LOAD-BEARING ASSUMPTION, AND A DEFECT IN THE FIRST VERSION OF IT
=================================================================================================
  K2 is only allowed to be asked if the engine may track slow ACTIVITY and forget fast
  BINDING. Full model: slow activity bit and fast binding bit per controller, binding
  gated by activity, targets reading the BOUND state. Coarse model: activity only.

  WHICH QUANTITY IS AVERAGED IS THE WHOLE THING. The drive exp(sum s m b / nC) is
  NONLINEAR in the binding state. The first version of this module substituted the mean
  OCCUPANCY inside it. Both are run below and the difference is the result.

  coarse tail, mean OCCUPANCY substituted : 1.247828e-01
  coarse tail, DRIVE averaged (correct QSS): 9.773204e-02   residual 6.8e-15

  The occupancy-substituted column does not converge -- it gets WORSE as the timescales
  separate, saturating near 28%. That is not a slow convergence, it is convergence to the
  WRONG LIMIT: separation makes the fast variable equilibrate, not become deterministic,
  and E[exp(X)] is not exp(E[X]) however fast X is. The drive-averaged column converges
  as 1/separation.

  K3: the correct coarse-graining reaches 1% on the TAIL at separation 30.0.
  Real separation, binding off-rate 0.0752/s over TF turnover at a 46 h half-life: 1.80e+04
  Margin: 6e+02x. K3 PASSES, and it passes on the CORRECTED averaging --
  the version that substitutes occupancy would have been wrong by 28% forever, with no
  amount of timescale separation revealing it.

K5  THE ASSEMBLED ENGINE, RUN
=================================================================================================
  Controller block wired by TRRUST, top controllers by OUT-degree, real signs, activity-
  level rates. Strata are PATHS through the controller chain -- in this block the state is
  the code, so a stratum is a single path and its mass is the path probability, which is
  exactly the prefix bound. Targets carried by the SIGNED CLASS COUNT times the shared
  TEMPORAL MULTIPLIER, which is the composed form multiplier.py measured.

  TWO DEFECTS IN THE FIRST RUN OF THIS GATE, FIXED HERE AND RECORDED.
  (a) A FIXED tau DOES NOT SCALE. Path probabilities fall like n^-L, so tau = 1e-6 was
      gentle at |C| = 4 and destroyed the answer at |C| = 8, where the certificate reached
      0.92 -- the pruner had dropped 92% of the mass and the tail it returned meant
      nothing. The threshold is now found by binary search against a stated error BUDGET,
      which is also the honest interface.
  (b) THE TARGET SET MOVED WITH |C|, so tails at different |C| were different observables
      and their comparison was meaningless. The target set is now fixed once, from the
      widest controller set, and carried unchanged at every |C|.

  TRRUST sha256[:32] 9b909319ccc8e36588b5a1bd3640e0df, 8403 distinct directed pairs.
  controllers by out-degree: SP1, NFKB1, RELA, TP53, JUN, STAT3, E2F1, SP3 ...
  60 target genes carried, FIXED across every row below, each with its real
  regulators among the controllers and TRRUST's own signs.

  Beyond that the PATH CAP binds before the width does: the retained set grows like n^L
  and the pruner cannot carry it, so the mass it drops shows up in the certificate. That
  is a real limit and it is reported rather than hidden by a gentler budget.

  The regime is worth about 117x in certificate at |C| = 6:
    prunable window   touches 22.3% of the tree, certificate 3.00e-03
    transition window touches 90.6% of the tree, certificate 3.51e-01
  Where exact enumeration is still affordable the pruned answer is checked against it
  rather than trusted, and it agrees to the fourth decimal at every such row.

=================================================================================================
K6  WHAT BREAKS FIRST
=================================================================================================
  The pruner touches n = 2^|C| children per surviving node, so its cost carries a factor
  2^|C| NO MATTER how well it prunes. Pruning removes the exponential in the WINDOW DEPTH
  and leaves the exponential in the WIDTH untouched -- which is what prune.py's nC sweep
  already said (kept ~ nominal^0.96) and what this assembly confirms in the node column.

  So the binding constraint is unchanged: the cap of 25 controllers from the
  representation work, and 36.5% of TRRUST's regulatory edges. Pruning does not move it.
  What pruning buys is that the WINDOW may now be refined for tail accuracy -- which
  history.py showed goes as dt^1.753 -- without paying 2^(|C| W / dt) for it.

=================================================================================================
K7  WHAT THIS DOES AND DOES NOT SETTLE
=================================================================================================
  1. K2 is a CRITERION and not a verdict on real cells. Settling it needs the joint
     distribution of TF protein half-life against target mRNA lifetime, per edge, which
     Schwanhausser's data could supply and this module does not use.
  2. K3's separation is measured on a two-controller synthetic system. The correct
     averaging is a general fact about nonlinear drives; the required separation is not.
  3. K5 is the engine's CONTROLLER BLOCK with real wiring, not a whole cell. Metabolism,
     trafficking, division and space are not in it, and the targets are carried by a
     fitted response rather than by mechanism.
  4. The rates here are a single activity timescale for every controller. Real TFs differ
     by orders of magnitude in turnover, and a mixture is not the same as its mean --
     which is exactly the lesson K3 just paid for.
