I4  WHAT THIS DOES NOT SETTLE
=================================================================================================
  1. An intact DBD is NECESSARY, not sufficient. Dimerisation, cofactor availability and
     localisation all still gate binding and none is modelled here.
  2. Only sequence-specific DNA binding is treated. Cofactors and chromatin regulators
     with no DNA_BIND annotation are never eligible, by construction.
  3. UniProt's named isoforms are curated, not exhaustive; transcript catalogues list more.
  4. The edges themselves remain gene-level in every artifact this repo ships. This module
     bounds them; it does not rewrite them.
