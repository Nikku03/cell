=================================================================================================
R8  COST AT FIXED ACCURACY vs HUB DEGREE  (added after R7, labelled)
=================================================================================================
  The question genome scale actually asks: to hold 1% tail error, how does each route's
  cost grow as the controller acquires more targets? SP1 has 484.
  (a) LOCAL observable, a conjunctive event over a bounded set of targets:
     k targets                route 1                route 2                route 3
  observable held FIXED at P(targets 0..3 all ON) for every k, so the only thing
  changing is the controller's degree.
             4       2^4 = 16 (exact)         2^5 = 32 (w=4)    2^14 = 16384 (L=12)    (P=1.67e-02)
             6       2^6 = 64 (exact)         2^5 = 32 (w=4)     2^12 = 4096 (L=10)    (P=3.70e-02)
             8      2^8 = 256 (exact)         2^6 = 64 (w=5)     2^12 = 4096 (L=10)    (P=5.91e-02)
            10    2^10 = 1024 (exact)         2^5 = 32 (w=4)     2^12 = 4096 (L=10)    (P=2.87e-02)

  (a) says: for a LOCAL event, bounded width wins outright and route 3 is 100x more
  expensive for the same accuracy. A width-4 bag holds the four observed targets exactly.

  (b) THE GLOBAL OBSERVABLE: relative error in Var(total ON count), which involves every
  pair and whose meaning does not change with k. Route costs held FIXED while k grows.
     k targets   exact Var   route 2, w=4   route 2, w=6   route 3, L=10
             4      1.0148      2.188e-16      2.188e-16       3.626e-03
             6      1.8247      9.313e-03      0.000e+00       5.272e-03
             8      2.9109      2.843e-02      7.572e-03       6.679e-03
            10      3.9207      4.348e-02      2.058e-02       7.898e-03

  On the GLOBAL observable route 2's error GROWS with the controller's degree at fixed
  width -- a bag cannot hold all k targets, so the covariances it misses accumulate --
  while route 3's is flat. Route 1's exact point is 2^k throughout and at SP1's 484 that
  is 2^484.

  THE ANSWER IS NOT A WINNER, IT IS A MATCHING. Local events over a bounded set of targets
  belong to bounded width, which represents them exactly and cheaply. Global events over
  everything a controller touches belong to controller history, which is the only
  representation whose error does not degrade as the controller acquires targets. Choosing
  one observable and declaring a winner is exactly how this gate went wrong twice.
